# loisugbe.com

Personal website for Lois Ugbe, sales trainer, speaker and founder.

A static site: `index.html` plus images and video in `assets/`. No build step.

## Deploy on Vercel

1. Import this repository in Vercel (Add New, Project).
2. Framework preset: Other. Leave the build command and output directory empty.
3. Deploy, then add `loisugbe.com` and `www.loisugbe.com` under Settings, Domains.

Every push to `main` redeploys the site.
